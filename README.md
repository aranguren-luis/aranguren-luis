## Sobre mí

> Ingeniero en Información especialista en **Quality Assurance**. Cuento con experiencia en **pruebas de caja negra, caja gris y caja blanca**, así como en la validación de **APIs**, pruebas funcionales y automatización con **Playwright**. He participado activamente en más de **11 proyectos** corporativos, asegurando la calidad en plataformas web, aplicaciones móviles y sistemas internos.
>
> Mi enfoque va más allá de la detección de defectos: **diseño estrategias de calidad** que integran análisis de requisitos, planificación de pruebas y métricas de rendimiento, alineadas con metodologías ágiles (Scrum/Kanban). Mi objetivo es que cada entrega no solo cumpla con los estándares técnicos, sino que **supere las expectativas del negocio y del usuario final**.

## Competencias Técnicas

**Tipos de prueba:** Caja negra (funcional sin acceso al código), caja gris (conocimiento parcial de la estructura), caja blanca (análisis interno del código), API e integración (validación de contratos, esquemas JSON y flujos entre servicios), autenticación y seguridad (flujos de auth, autorización y vulnerabilidades comunes).

**Automatización:** Playwright (E2E), Postman/Newman (API), JavaScript, GitHub Actions (CI), SonarCloud (análisis estático de calidad), Cucumber (BDD).

**Bases de datos:** Consultas SQL para validación en backends, scripts de limpieza y preparación de datos, verificación de integridad referencial y consistencia post-ejecución.

**Gestión de QA:** Planificación y diseño de casos, matrices de trazabilidad, ejecución con reportes de resultados. Métricas clave: P95, tasa de errores y throughput. Reportes en HTML/JSON publicados en GitHub Pages. Herramientas: ClickUp, YouTrack.

**Metodologías:** Scrum (participación en todas las ceremonias), Kanban (flujo continuo), colaboración con equipos multidisciplinarios.

**Control de versiones:** Git y GitHub (ramas, pull requests, revisiones de código), publicación de artefactos en GitHub Pages.
